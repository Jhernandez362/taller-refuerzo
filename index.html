Ejercicio 3: Validación de Formulario en Tiempo Real

Crea un formulario con un campo para contraseña. A medida que el usuario escribe, verifica en tiempo real si el texto tiene al menos 8 caracteres. Si cumple la condición, pinta el borde del input de verde; si no, píntalo de rojo o muestra un mensaje de advertencia debajo.

La contraseña debería tener 8 caracteres.
